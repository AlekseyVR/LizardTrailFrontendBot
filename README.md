# 🏍 LizardTrail — Telegram-бот и Mini App для эндуро-проката

Система онлайн-бронирования для эндуро-проката, школы и сервиса: клиент оформляет
заявку в Telegram Mini App, менеджер ведёт записи в админ-календаре, все данные —
в Google Таблице.

## ✨ Возможности

### Клиент (Mini App)

| Экран | Что делает |
|---|---|
| Стартовый (`index.html`) | Карточка «Прокат и Тренировки», адрес базы (ссылка на Яндекс.Карты), блок «Команда LizardTrail» |
| Маршрут (`booking/training.html`) | Кол-во человек, уровень, аренда мотоцикла, контакты, пожелания по дате и времени, комментарий |
| Сервис (`booking/service.html`) | Мотоцикл, проблема, желаемая дата, контакты |
| Заставка загрузки | Логотип + крутящееся колесо + «Powered by AVR Logic» |

### Менеджер (админка, `admin.html`)

- **Календарь** — день / неделя / месяц; пересекающиеся события раскладываются
  «дорожками», на блоках видно число участников и статус.
- **Записи** — создание, редактирование, удаление: услуга (время окончания
  считается по длительности), «Другое» (своя услуга + цвет), предоплата
  (комментарий обязателен), отмена брони.
- **База клиентов** — имя, телефон, описание, чёрный список (`banned` — серая
  строка и лейбл), история маршрутов клиента.
- **Групповые записи** — выбор нескольких клиентов через полноэкранный пикер
  (поиск + чекбоксы).
- **Авто-клиенты** — при сохранении записи клиенты заводятся или подтягиваются
  по номеру телефона.
- **Авто-завершение** — прошедшие неотменённые записи считаются «Завершено».
- **Канбан сервиса** — сервисные заявки по статусам.
- **Настройки** — услуги, сотрудники (Owner), получатели уведомлений (Owner).

### Уведомления

- **Новая заявка** → сообщение получателям в Telegram.
- **Подтверждение клиенту** (при сохранении записи менеджером):
  - есть Telegram ID → бот отправляет подтверждение сам;
  - нет → попап с кнопками **Viber** / **WhatsApp** и готовым текстом в буфере.
- При редактировании — только если изменились **дата или время**.

## ⚙️ Как это работает

### Заявка из Mini App

1. Клиент открывает Mini App по кнопке бота и заполняет форму.
2. Фронт отправляет запрос на API с заголовком `X-Telegram-Init-Data`.
3. Бэкенд валидирует подпись, сохраняет заявку в «Записи» и заводит клиента в базу.
4. Получатели уведомлений получают сообщение в Telegram.

### Запись, созданная менеджером

1. Менеджер заполняет карточку и жмёт «Сохранить».
2. Бэкенд сохраняет запись, заводит или подтягивает клиентов по телефону.
3. Если у клиента есть Telegram ID — бот отправляет ему подтверждение
   (текст из `message_template.txt` с подставленными датой и временем).
4. Если нет — менеджеру показывается попап с кнопками Viber/WhatsApp и текстом
   в буфере обмена.
5. При редактировании уведомление уходит только если изменились дата или время.

### Авто-завершение

Запись с прошедшей датой и статусом не «Отменена» отображается как «Завершено»
(вычисляется при чтении; сама таблица не меняется).

## 🗄 Данные (Google Sheets)

| Лист | Колонки |
|---|---|
| **Менеджеры** | Telegram ID, Имя сотрудника, Роль, Дата добавления |
| **Записи** | ID, Дата, Время начала, Время окончания, Имя (Главный), Телефон, Услуга, Стоимость (Итого), Участники (JSON), Комментарий, Статус, Цвет (HEX), Предоплата |
| **Сервис** | сервисные заявки (канбан) |
| **Услуги** | каталог услуг (название, длительность, цена, цвет) |
| **Клиенты** | ID, Имя, Телефон, Username, Telegram ID, Дата создания, Описание, is_black_list |
| **Уведомления** | Telegram ID, Имя, Дата добавления |

Статусы записи: `Активна` / `Завершено` / `Отменена`.

## 🔌 API

Все админские эндпоинты требуют заголовок `X-Telegram-Init-Data`.

| Метод | Путь | Доступ | Назначение |
|---|---|---|---|
| GET | `/`, `/health` | — | проверка живости |
| GET | `/api/me` | любой | роль текущего пользователя |
| POST | `/api/booking/training` | любой | заявка на маршрут |
| POST | `/api/booking/service` | любой | заявка на сервис |
| GET | `/api/admin/data` | менеджер | все данные одним запросом |
| — | `/api/admin/entries` | менеджер | записи (GET/POST/PUT/DELETE) |
| — | `/api/admin/service` | менеджер | сервисные заявки |
| — | `/api/admin/services` | менеджер | каталог услуг |
| — | `/api/admin/clients` | менеджер | база клиентов |
| — | `/api/admin/managers` | **Owner** | сотрудники |
| — | `/api/admin/notifications` | **Owner** | получатели уведомлений |

## 🔐 Безопасность

- **initData** валидируется через `safe_parse_webapp_init_data` (HMAC от Telegram)
  плюс проверка свежести `auth_date` (24 ч) — подделать без токена бота нельзя.
- **Роли** — по листу «Менеджеры» (`require_manager` / `require_owner`).
- **CORS** ограничен адресом фронта (`https://alekseyvr.github.io`).
- **Секреты** (`.env`, `google_key.json`) не коммитятся и лежат только на сервере.

> ⚠️ Беречь в первую очередь: `BOT_TOKEN` (позволяет подделать initData)
> и `google_key.json` (прямой доступ к таблице).

## 🚀 Запуск локально

### Бэкенд

```bash
cp .env.example .env        # заполнить BOT_TOKEN, ADMIN_ID, SPREADSHEET_ID, WEBAPP_URL
# положить google_key.json рядом с main.py

python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate.bat
pip install -r requirements.txt
python main.py
```

API поднимется на `http://localhost:8001` (порт задаётся в `.env` через `PORT`).

> Бот работает через long-polling — отдельный адрес/порт для него не нужен,
> он сам обращается к Telegram.

### Windows

Двойной клик по `run.bat` — создаст venv, установит зависимости и запустит бэкенд.

### Фронтенд

Статика, сборка не требуется:

```bash
cd webapp && python3 -m http.server 5500
```

Перед запуском в `js/config.js` указать `window.API_BASE = 'http://localhost:8001'`.

## 📦 Деплой

### Фронт (GitHub Pages)

1. Push в ветку `main` репозитория `LizardTrailFrontendBot`.
2. Workflow `.github/workflows/pages.yml` публикует папку `webapp/`.
3. Settings → Pages → Source = **GitHub Actions**.

### Бэкенд

1. Разместить на сервере (VPS или домашний ПК), заполнить `.env` + `google_key.json`.
2. Запускать `python main.py` постоянно (systemd / автозапуск Windows).
3. Публичный HTTPS-адрес — через **Cloudflare Tunnel** (постоянный домен).
4. Прописать этот адрес в `webapp/js/config.js` (`window.API_BASE`).
